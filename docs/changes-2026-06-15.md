# Changes 2026-06-15

打通 Android 发布流程。有了 Samsung A16 实体测试机，目标两种产物：**AAB → Google Play**、**universal APK → 装 A16 测试 + 上其他 Android 商店**，两者用同一 upload keystore 签名。详见 `docs/ANDROID_DEPLOY.md`。

## 生成 android/ 平台

`npx cap add android` 生成 Capacitor Android 工程。云端沙盒挂载对 `android/` 有 EPERM（不能 unlink），`cap add`/`cap sync` 的善后步骤中断，留下若干半成品，已手动修正：

- `android/app/build.gradle`：`namespace` / `applicationId` 从默认占位 `com.getcapacitor.*` 改为 `com.gamestao.sumquest`；`versionCode` / `versionName` 改为可被 `-PversionCode` / `-PversionName` 注入（默认 1 / 1.0.0）。
- `MainActivity.java`：package 声明修正为 `com.gamestao.sumquest`（原为默认包，与目录不符会编译失败），并清掉文件末尾一个多余 NUL 字节。
- `strings.xml`：`app_name` → SumQuest，`package_name` / `custom_url_scheme` → `com.gamestao.sumquest`。
- `assets/`：放入图标源图（`icon.png` 1024²、`splash.png`），供 `capacitor-assets generate` 用。

## CI：release-android.yml

- 基底从 `build:crazygames` 改为 `build:mobile`（高清 mobileAssets，与 README/`deploy:android` 一致）。
- 一次构建产出 **AAB（`bundleRelease`）+ universal APK（`assembleRelease`）**，均用同一 keystore 经 AGP 注入式签名。
- `versionName` 取自 git tag（`v1.2.3` → `1.2.3`）或 `package.json`；`versionCode` 取 GitHub run number（单调递增，满足 Play 要求）。
- 新增 `publish_play` 手动开关：手动触发时可只出包不发 Play。
- 两个产物都作为 artifact 上传。

## keystore 与安全

- `tools/gen-android-keystore.ps1` / `.sh`：本机一键生成 upload keystore（私钥不经过云端），并输出 base64 供 GitHub secret。
- `.gitignore`（根 + `android/`）加固：忽略 `*.keystore` / `*.jks` / `*.keystore.b64`，防止误提交签名文件。
