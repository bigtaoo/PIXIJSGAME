# Changes 2026-06-12

小关过关庆祝特效升级:节奏编排 + 放大 + screen shake。验证:新增/改动代码经 `transpileModule` 语法检查通过;沙箱挂载副本异常,完整 `tsc` / `npm run build` 需本地确认。

## 庆祝特效重构(`showTargetClearCelebration` in `gameScene.ts`)

粒子预算锁在 50,从"匀速随机 50 个满级爆炸"改为三拍节奏编排:

- **开场齐射**:4 个 focus 爆发在 0–120ms 几乎同时炸出中心,配合 screen shake 制造"砰"的顶点
- **扩散高潮**:剩余 6 个 focus + 34 个 ambient,按到中心距离向外扩散(触发时间 cap 在 SPREAD 的 82%,给收尾留窗口)
- **收尾波**:末 18% 在中心补 6 个 cluster,首个为大 focus 收口

常量:`CELEBRATION_FOCUS_BURSTS=10` / `CELEBRATION_OPENING_BURSTS=4` / `CELEBRATION_AMBIENT_BURSTS=34` / `CELEBRATION_FINALE_BURSTS=6`。

分层(兼顾性能):focus = `combo×3`(19 粒子 + ripple + glow),ambient = 普通爆炸(11 粒子)。总粒子约 630,低于旧版 50×combo 的 ~950——更热闹且峰值更低。

## 特效放大(`effect.ts` / `effectManager.ts`)

- `ExplosionSystem.play` 与 `EffectManager.playEffect` 新增 `sizeMul` 参数(默认 1,不影响游戏内普通消除)
- 庆祝中:ambient ×1.3,focus ×1.5
- focus 的 ripple 圆环与 glow 光晕同步随 `sizeMul` 放大:`Ripple` 新增 `scale` 字段,`spawnRipple` / `spawnGlow` 接收倍数,`updateRipples` 半径乘 `scale`、`spawnGlow` sprite scale 乘 `sizeMul`——避免出现"碎片大、光环小"的不协调

## Screen shake(`gameScene.ts`)

- 新增 `triggerShake(magnitude, durationMs)` 与 `updateShake(deltaMs)`:偏移 `this.x` / `this.y`(base 0,0)做随机抖动,按 `k = 1 - elapsed/duration` 线性衰减归零
- `update()` 每帧调用(暂停期间也跑,因庆祝时 `isPause = true`)
- 开场齐射时触发:`gridSize * 0.2`,350ms
- 纯程序抖动,PC + 移动通用,**非**设备马达震动(`navigator.vibrate`)
