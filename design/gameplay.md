# 数字消除游戏 策划文档

**版本：** v1.0  
**日期：** 2026年5月

---

## 1. 游戏概述

一款数字配对消除小游戏，玩家需要在限定时间内找出棋盘上两个加和等于目标数字的数，将其消除。游戏共 19 关，目标数字从 6 逐渐增加至 99，格子数量随进度扩大，难度呈自然曲线上升。

| 项目 | 内容 |
|------|------|
| 技术平台 | PixiJS（Web）/ 微信小游戏双端 |
| 目标平台 | CrazyGames 及微信小游戏 |
| 单局时长 | 约 5 分钟（前期测试数据） |
| 游戏类型 | 休闲益智 / 数字解谜 |

---

## 2. 核心玩法

棋盘上随机分布若干数字。玩家点击任意一个数字将其选中，再点击另一个数字，若两数之和恰好等于当前关卡的**目标数字（Target）**，则两个数字同时消除，并触发爆炸特效。消除所有数字即通过本轮。

### Header 等式显示

顶部 Header 通过等式实时反映选中状态，以视觉语言代替文字说明：

| 状态 | 显示内容 | 说明 |
|------|----------|------|
| 初始 / 重置后 | `□ + □ = 6` | 两个空槽提示玩家需要选两个数字 |
| 选中第一个数字后 | `5 + □ = 6` | 所选数字填入左槽，右槽仍为空，引导玩家继续选择 |
| 消除成功后（短暂） | `5 + 1 = 6` | 展示完整等式约 0.5 秒作为结果反馈，随后重置为空槽 |
| 选中后点击无效格子 | 保持当前状态 | 不重置，避免打断选择流程 |

此设计无需任何教程文字，玩家在第一次点击后即可通过等式变化直觉理解规则，符合隐性引导原则。

### 2.1 难度曲线的核心逻辑

难度并非来自规则复杂化，而是来自以下三个自然因素的叠加：

- **配对稀疏**：目标数字越大，有效配对的范围越宽，但棋盘上每种数字的出现频率越低（如 Target=8 时点击 3，棋盘上可能有多个 5 可选；Target=18 时点击 3，只有一个 15，且更难辨认）
- **视觉噪音**：格子数量随关卡扩大，搜���难度上升
- **识别难度**：数字范围扩大至两位数后，相近数字（如 52 和 53）视觉区分难度增加

## 4. 时间机制

每关的五个 Target 共用一个**时间池**，时间可以跨 Target 积累和消耗。

### 4.1 时间池规则

- 每进入一个新的 Target，时间池 **+30 秒**
- 未用完的时间延续到下一个 Target，**不清零**
- 每成功消除一对数字，根据连消状态获得时间奖励（详见 4.3）
- 时间池归零即判定为本轮失败，扣除一条命

### 4.2 策略价值

该机制使前期简单的 Target 具有策略意义——玩家若能快速消除，便可将节省下来的时间储备给后期更难的 Target。这鼓励玩家追求「清得快、清得干净」，而非仅仅「清完就行」。

### 4.3 连消加时规则

**连消定义：** 上一次消除完成后 **3 秒内**再次完成消除，即视为连消。超过 3 秒未消除则连消计数重置。

| 连消次数 | 本次加时 |
|----------|----------|
| 第 1 次（或连消中断后首次） | +2 秒 |
| 第 2 次连消 | +3 秒 |
| 第 3 次及以后 | +4 秒（上限） |

**设计意图：** 基础加时定为 +2 秒，使单次消除本身即有价值；连消是锦上添花，而非生存必要条件。具体数值待平衡性测试后调整。

### 4.4 加时视觉反馈

消除成功后，一个显示加时量（如 `+2s`）的文字精灵从**两格中心点**飞向 Header 区域的**闹钟图标**，轨迹为轻微抛物线弧形。闹钟接收后执行短促弹跳动画（scale 1 → 1.3 → 1），时间数字短暂高亮，使玩家直观感知时间被充能。详见《美术文档》。

## 5. 生命系统

| 属性 | 规则 |
|------|------|
| 每关命数 | 3 条 |
| 失败条件 | 时间池归零时仍有未消除的数字 |
| 扣命后 | 时间池重置，从本关**第一个** Target 重新开始 |
| 3 命耗尽 | 重置至本关起点，时间池和命数全部刷新（可重试） |

命数在关卡切换时刷新。玩家进入下一关时，恢复 3 条命和空时间池。

## 7. 数字生成规则

- **生成范围**：1 到 Target−1，完全随机
- **配对方式**：随机取 `first ∈ [1, Target−1]`，`second = Target − first`，两者成对写入棋盘
- **可解性保证**：棋盘始终可解（每个数字均与其配对数字共同生成）

### 7.1 ��位数显示

- 单位数（1–9）：使用完整精灵图尺寸
- 两位数（10–98）：复用已有精灵图，缩放至格���尺寸的 **70%**，两个数字并排居中显示
- 最大数字为 98（Target=99 时范围为 1–98），无需三位数支持

### 7.2 难度体感说明

Target 较小时，有效数字种类少，棋盘上同一数字出现频率高，容易找到配对；Target 较大时，有效数字种类多但稀疏，且均为两位数、视觉区分难度高，同时格子数量更多，搜索难度大幅上升。难度曲线自然成立，无需额外调参。

---

## 8. 提示系统

为降低玩家卡关时的挫败感，引入**被动式微弱提示**：

- 玩家选中某数字后，若 **3 秒**内未找到配对数字
- 棋盘上与所选数字配对的另一半数字会产生一次**微弱闪烁**
- 闪烁强度刻意设计得较弱，使玩家感觉仍是「自己发现」的，保留解题成就感
- 提示**仅触发一次**，不循环，避免破坏游戏挑战性

---

## 9. 进度存档

| 属性 | 规则 |
|------|------|
| 存储方式 | localStorage（Web 端）/ wx.storage（微信端） |
| 存档粒度 | 当前关卡编号（关卡起点） |
| 读档行为 | 重新打开游戏后，直接进入上次所在关卡的起点，命数和时间池刷新 |

存档精度定为关卡起点（而非具体 Target），避免玩家感觉「永远卡在某一关的某一步」，重新开始一关有助于玩家重拾节奏。

---

## 10. 新手引导

前两关��Target 6–10、11–15）作为自然引导关卡：

- Target 较小，数字种类少，配对直觉明显，玩家无需说明即可理解核心规则
- 格子数量最少（3×6），视觉干扰最低
- 时间充裕，便于玩家自然发现「节省时间」的策略价值

**无需额外弹窗教程**，通过关卡本身设计完成隐性引导。Header 等式的空槽设计（见第 2 节）也是隐性引导的一部分：玩家点击第一个数字后，等式从 `□ + □ = 6` 变为 `5 + □ = 6`，无需任何文字即可传达"还需要再选一个数"的信息。

## 11. 大厅与场景流程

```
首次打开（新玩家）
  └→ 直接进入第 1 关

通关第 1 关后
  └→ 下次打开显示关卡大厅
       ├→ 选择任意已解锁关卡
       └→ 进入对应关卡游戏
```

关卡大厅中：
- 已通关关卡：绿色高亮
- 当前关卡（最高进度）：金色高亮
- 未解锁关卡：灰色半透明，不可点击
