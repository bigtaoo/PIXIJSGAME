# 留存系统设计文档

**版本：** v1.0  
**日期：** 2026年5月  
**适用平台：** CrazyGames（Web）

---

## 概述

本文档涵盖两个留存外围系统：**每日挑战**和**关卡星级评分**。两者均基于现有核心玩法扩展，不引入道具或货币体系。

---

## 1. 每日挑战

### 1.1 定位

区别于正式关卡的独立模式，给已通关玩家提供每日回访动力，同时通过 CrazyGames 周榜提供社交竞争维度。

### 1.2 解锁条件

通关第 1 关（Target 6–10）进入关卡大厅后，每日挑战入口永久解锁。

### 1.3 模式规则：限时乱斗

| 属性 | 规格 |
|------|------|
| 时长 | **90 秒**，固定倒计时 |
| 棋盘 | **6 × 8 = 48 格**，固定不变 |
| 模式特征 | 限时内尽可能多地消除配对，追求得分 |

玩法与正式关卡的核心操作一致（点选两数之和等于 Target 即消除），但节奏更快、目标从「通关」变为「刷分」。

### 1.4 每日 Target

每天的目标数字由**日期决定**，全服所有玩家共享同一 Target：

```
Target = (当日为今年第 N 天 % 31) + 20
```

取值范围：**20 – 50**，每 31 天为一个循环。难度适中，适合泛用户群。

### 1.5 棋盘生成

使用**日期字符串作为随机种子**（如 `"2026-05-23"`）生成棋盘，保证全服同一天面对完全相同的初始局面，确保排行榜公平性。无需后端支持，纯客户端实现。

### 1.6 补行机制（类俄罗斯方块）

消除后棋盘**不立即补数**，留有空洞：

1. 消除配对 → 对应两格变为空位
2. 当某一**整行**（横向 6 格）全部清空时触发补行
3. 该空行以上的所有数字**整体下落一行**
4. 顶部补入**新的一行（6 格 = 3 对）**

**新行生成规则：**
- 与当日 Target 一致
- 6 个数字内部自成配对（3 对），不依赖棋盘现有数字
- 保证任意时刻棋盘整体均可解

### 1.7 得分规则

沿用正式关卡的连消系数，但将「加时间」替换为「加分」：

| 消除状态 | 本次得分 |
|----------|----------|
| 普通消除 | **+2 分** |
| 连消第 1 次 | **+3 分** |
| 连消第 2 次 | **+4 分** |
| 连消第 3 次及以上 | **+5 分**（封顶） |

**连消判定：** 上次消除完成后 **3 秒内** 再次完成消除即为连消，超时重置计数。

### 1.8 重玩机制

当日挑战**可重复游玩**，取该玩家当日**最高分**上榜。鼓励玩家练习后反复提交，提升日内留存。

### 1.9 本地分数存储

每次结算后，将 `{ date, score }` 写入 `localStorage`：

```js
localStorage.setItem('dailyChallenge', JSON.stringify({
  date: "2026-05-23",
  score: 42
}));
```

读取时若日期不匹配则视为新的一天，显示「今日最佳：-- 分」。游戏内 UI 并列展示：
- **今日最佳**（本地存储）
- **本周排名**（CrazyGames 周榜）

### 1.10 CrazyGames 排行榜集成

CrazyGames 排行榜目前为 **MVP 阶段**，每周一 07:00 UTC 重置。每日 Target 不同天自然区隔挑战内容，周榜作为竞争载体。

**配置参数（需联系 CrazyGames 管理员设置）：**

```json
{
  "leaderboardGuide": "Daily Challenge - Score as many points as possible in 90s",
  "encryptionKey": "<32字节 base64 密钥，开发者自行生成>",
  "scoreLabel": "POINTS",
  "scoreSorting": "DESC",
  "minValue": 0.0,
  "maxValue": 9999.0,
  "cooldownSeconds": 30,
  "isIncremental": false
}
```

**分数提交代码（HTML5）：**

```js
const encryptedScore = await encryptScore(finalScore, encryptionKey);
CrazyGames.SDK.user.submitScore({ encryptedScore });
```

`encryptScore` 函数使用 AES-GCM 加密，参考 CrazyGames 官方文档实现。提交时机：90 秒倒计时结束后立即提交。

### 1.11 连续挑战天数计数器

在关卡大厅显示「**连续挑战 X 天**」，不绑定奖励，利用玩家对连续性数字的心理依赖形成回访习惯。

```js
// localStorage 存储结构
{
  lastChallengeDate: "2026-05-23",
  streakDays: 5
}
```

逻辑：每次完成每日挑战后，若 `lastChallengeDate` 为昨天则 `streakDays++`，否则重置为 1。

## 2. 关卡星级评分

### 2.1 定位

给已通关的关卡引入「完美通关」目标，驱动玩家回练，延长正篇内容的有效寿命。

### 2.2 评分标准

| 星级 | 条件 |
|------|------|
| ⭐ | 通关（无论扣了几条命） |
| ⭐⭐ | 通关 + 全程未扣命（一次性清完所有 Target） |
| ⭐⭐⭐ | 通关 + 未扣命 + 最终剩余时间 ≥ 15 秒 |

**设计说明：**
- 使用「是否扣命」而非「时间阈值」作为二星条件，跨关卡统一标准，无需 per-level 调参
- 15 秒为三星时间阈值初始值，需根据实际测试调整
- 对玩家透明：失败原因明确，知道如何改进

### 2.3 存档

每关星级存入 `localStorage`，key 为关卡编号，只记录最高星级：

```js
// 存储结构示例
{
  "levelStars": {
    "1": 3,
    "2": 2,
    "3": 1,
    ...
  }
}
```

重玩只在取得更高星级时覆盖。

### 2.4 关卡大厅显示

在现有关卡按钮（绿色/金色/灰色三色方案）上叠加星级图标：

| 状态 | 显示 |
|------|------|
| 未解锁 | 灰色半透明，无星 |
| 已通关 | 绿色高亮 + 1–3 颗星图标 |
| 当前最高进度关卡 | 金色高亮 + 已获星级 |

不改变现有布局，星级图标叠加在按钮角落即可。
